# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [2.0.0] - 2025-11-19

### Added
- SilverStripe 6 compatibility
- PHP 8.3+ support

### Changed
- Updated `lekoala/silverstripe-cms-actions` to ^2.0
- Validation classes moved to new namespaces
- Form validation API updated to SilverStripe 6 standards

### Removed
- SilverStripe 4/5 support (use 1.x for SS4/SS5)

## [1.0.0] - 2023-01-01

### Added
- Initial release with SilverStripe 4 & 5 support
- User invitation via email
- CMS admin interface for managing invitations
- Frontend invitation form
- User group assignment support
- Invitation expiry configuration
